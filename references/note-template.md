# Note Template

Use this template when the conversation has enough depth to justify a cumulative reading note.

## Paper

- title
- authors if known
- venue or year if known
- source file or link

## User Goal

- why the user is reading this paper
- current background level if known

## Paper Map

- problem
- core idea
- method pipeline
- experiments
- conclusion

## Hard Parts Encountered

- sections or subsections
- formulas
- figures or tables
- code blocks or pseudocode
- cited references
- terminology or background assumptions

## Clarifications Resolved

- misconception or confusion
- clarified explanation
- page or section reference

## Open Questions

- unresolved details
- follow-up topics to search or revisit

## Next Steps

- which section to reread
- which concept to study next
- whether to produce a shorter review or implementation notes
